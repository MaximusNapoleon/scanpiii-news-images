# Images des nouveautés Scanpiii

Un dossier par version de l'app (ex. `1.6.3/`), une image PNG par nouveauté.

Le nom du fichier est celui indiqué dans la liste des nouveautés après `img:`
(ex. `img: 1.6.3/sunmi-d3-mini.png` → déposer `sunmi-d3-mini.png` dans le
dossier `1.6.3/`). Minuscules, sans accents, et on ne renomme jamais un
fichier déjà déposé.

Pour déposer : ouvrir le dossier de la version → « Add file » →
« Upload files » → glisser le PNG → « Commit changes ».
